# Java, Spring Boot, and SQL Learning Projects

Welcome to my Java, Spring Boot, and SQL learning repository. This repository contains a series of projects and exercises that document my progress and learning journey as a backend developer.

## Overview

The repository is structured into progressive learning modules, starting from the fundamentals of Java and Object-Oriented Programming (OOP) to advanced topics like Spring Boot, REST APIs, and Database Management with SQL and Hibernate.

## Tech Stack

- **Language:** Java
- **Frameworks:** Spring Boot, Hibernate
- **Database:** SQL
- **Tools:** IntelliJ IDEA, Git

## Directory Structure

Each directory represents a specific topic or sprint in the curriculum. Inside each folder, you will find a dedicated `README.md` explaining the core concepts covered and the implementation details of the project.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/omersabribalci/Workintech-Java-Learning-Projects.git
   ```
2. Open the desired project folder using an IDE like IntelliJ IDEA.
3. Resolve dependencies and run the main application or test files.
