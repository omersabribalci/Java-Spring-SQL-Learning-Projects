# Java, Spring Boot, and SQL Learning Projects

## Overview
This repository contains a structured learning path covering Java fundamentals, OOP, SQL, Spring Boot, JPA/Hibernate, security, and testing. Each project is designed to build practical backend development skills step by step.

## Project Progression
The repository is organized from beginner to advanced topics:

- Java basics and object-oriented programming
- Data structures and algorithmic thinking
- SQL fundamentals and database operations
- Spring Boot and dependency injection
- REST API development with JPA and Hibernate
- Security and authentication
- Testing in Spring applications

## Tech Stack
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- SQL/PostgreSQL
- Maven
- IntelliJ IDEA

## How to Run
1. Clone the repository.
2. Open the desired project folder in IntelliJ IDEA or another Java IDE.
3. Import Maven dependencies.
4. Run the application or relevant tests for that project.

## Learning Goal
The main goal of this repository is to practice and strengthen backend development skills through hands-on projects and real-world patterns used in Java and Spring applications.
