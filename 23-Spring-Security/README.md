# Spring Security Project

## Overview
This project demonstrates the core concepts of Spring Security. It includes practical exercises and examples to build a strong understanding of authentication, authorization, and secure API design in Spring Boot.

## Project Structure
- Source code is organized into logical packages reflecting the concepts learned.
- Security configuration, controllers, services, entities, and repositories are separated by responsibility.
- Where applicable, tests are included to verify functionality.

## Key Concepts Applied
- **Spring Security**: Implementing authentication and authorization in a Spring Boot application.
- **Secure REST API**: Protecting endpoints and managing access rules.
- **JDBC / Role-Based Access**: Managing users, roles, and permissions.
- **Clean Code**: Adhering to naming conventions and project structures.

## Usage
To run or explore this project:
1. Open the project in your preferred IDE (e.g., IntelliJ IDEA).
2. Navigate to the main application class and the security configuration classes.
3. Run the application and test the protected endpoints with the configured roles and credentials.
